# Student Performance & Retention Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyse student performance, attendance patterns, and retention outcomes. The solution helps educational institutions identify at\-risk students, monitor academic progress, and support data\-driven decision\-making.

## Business Problem

Educational institutions often face challenges in identifying students who are likely to underperform or discontinue their studies. Without timely insights, institutions may struggle to improve student success and retention rates.

This dashboard addresses these challenges by providing a comprehensive view of academic performance, attendance behaviour, and retention trends.

## Dataset Information

The project uses a dataset containing 500 student records with the following attributes:

- Student ID
- Age
- Gender
- Department
- Attendance Rate
- Study Hours per Week
- Midterm Score
- Final Score
- GPA
- Parental Education
- Extracurricular Activities
- Scholarship Recipient
- Dropout Risk
- Retention Status

## Key Insights

- Students with higher attendance generally achieve higher GPAs.
- Academic performance varies across departments.
- Attendance and study hours significantly influence final outcomes.
- Early identification of high\-risk students can improve retention rates.
