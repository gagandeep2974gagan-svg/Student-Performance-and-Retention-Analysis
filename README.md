# Student-Performance-and-Retention-Analysis
This project analyses student academic performance, attendance, engagement, dropout risk, and retention trends using a synthetic dataset of 500 student records. The dashboard helps identify key factors influencing student success and retention through interactive visualisations and KPI tracking.
Student Performance & Retention Analytics Dashboard
Overview
This Power BI project focuses on analysing student performance and retention patterns to support data-driven decision-making in educational institutions.

The dashboard provides insights into:

Student academic performance (GPA, assignments, exams)
Attendance trends
Student engagement metrics
Dropout risk analysis
Retention rate monitoring
Department-wise performance comparison
Dataset
The project uses a synthetic dataset containing 500 students records created for portfolio and educational analytics purposes.
